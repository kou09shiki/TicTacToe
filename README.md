#  Tic Tac Toe 🎉

A fun and colorful **Tic Tac Toe** game built with **Java Swing**.  
Designed with a bubbly UI, hover effects, and playful animations for each click. Perfect for a small desktop game project or learning Java GUI development.

---

## Features

- 3x3 Tic Tac Toe board.
- Two-player game (X and O).
- Bubbly hover effects on buttons.
- Click animation to make the game lively.
- Win/draw detection with popup messages.
- Reset board automatically after a game ends.

---
## Technologies Used

- **Java** – Core programming language.
- **Swing** – For GUI design and components.
- **AWT** – Event handling and graphics.
